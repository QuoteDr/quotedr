# QuoteDr Tutorial Data

`quotedr-tutorial-clients.csv` is a fictional client list for tutorials, demonstrations, and advertising recordings.

Import it from **Settings > Pricing & Data > Clients** using the existing file upload. The columns exactly match QuoteDr's client export format:

`Name,Phone,Email,Address,City,Notes`

Use it with a fresh tutorial account. Importing a client list replaces that account's existing saved clients.

All phone numbers use the reserved fictional `555-01xx` range, all email addresses use `example.com`, and no real client information is included.
